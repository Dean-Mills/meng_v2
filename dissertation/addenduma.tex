\chapter{Reproducibility: Run and Sweep Identifiers}
\label{appendix_repro}

Every experimental result in this document traces to a logged run in the Weights \& Biases project
\texttt{deanmills/multiperson-pose-grouping}.
Each training run records its full configuration, source-code state, training curves, and checkpoint;
evaluation results are attached to the source run's summary under \texttt{eval/*} prefixes
(Section~\ref{sec_meth_evaluation_wandb}).
This appendix lists the identifier for every run and sweep cited in the body of the document.
The run identifier doubles as the on-disk output directory name under \texttt{outputs/<config>/<run>/}.

\section{Evaluation attachments}
\label{appendix_repro_evals}

Evaluation metrics are attached to the source training run's W\&B summary rather than logged as separate runs.
The headline run \texttt{b5noyg7t} carries the following evaluation prefixes:
\texttt{eval/e2e} (HigherHRNet end-to-end, oracle and predicted $K$),
\texttt{eval/e2e\_yolo} and \texttt{eval/e2e\_rtmo} (the detector-swap evaluations of Section~\ref{sec_res_e2e_swap}),
\texttt{eval/k\_estimation/coco} (K-head accuracy on ground-truth keypoints),
and \texttt{eval/knn/coco\_multi} (the multi-person diagnostic subset).
Every other run listed above carries evaluation summary fields from the corresponding COCO evaluation pass.
Metric keys retain the codebase's historical field names,
in which the $k$-means read-out is recorded as \texttt{knn} (for example \texttt{knn\_pga});
every \texttt{knn}-named field therefore reports the $k$-means read-out of Section~\ref{sec_meth_problem_subproblems}.
The K-head checkpoint used by the autonomous pipeline was trained before the W\&B integration
and is preserved on disk under \texttt{outputs/k\_head\_meng\_headline\_coco/a636b1c4/};
its evaluation results are attached to \texttt{b5noyg7t} as listed above.
